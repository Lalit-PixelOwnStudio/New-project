# Interior Designers ke liye Website Pitch: Call Script

**Caller:** Prachi, PixelOwn Studio

**Tone:** Soft aur respectful rakho, jaise aap help offer kar rahe ho, bech nahi rahe. Pehle permission lo, phir introduce karo, aur pitch ki jagah sawaal poochho.

---

## Script 1: Main Call

### Step 1: Opening (permission pehle)

> "Hello, good morning/afternoon! Kya meri baat **[Designer ka naam]** ji se ho rahi hai?"

_(Haan bolein toh:)_

> "Thank you! Kya aapke paas **2 minute** hain? Agar abhi busy hain toh main baad mein call kar sakti hoon, aap hi bata dijiye kab theek rahega."

**Agar busy hain:**

> "Bilkul, koi baat nahi. Kal subah ya shaam, kab call karna better rahega?"

_(Time note karo, "Thank you, have a great day!" bolo aur call end karo.)_

### Step 2: Introduction

> "Thank you so much! Mera naam **Prachi** hai aur main **PixelOwn Studio** se baat kar rahi hoon. Hum interior designers aur architects ke saath kaam karte hain, taaki unka kaam online sahi tareeke se showcase ho aur unhe naye clients mil sakein."

### Step 3: Jab woh poochhein "Haan, kis regarding hai?"

Yahan seedha pitch mat karo, sawaal poochho:

> "Actually ek chhota sa sawaal tha. Abhi aapke paas naye clients mostly kahan se aate hain? Referrals se, Instagram se, ya Google se?"

_(Unhe bolne do aur dhyan se suno.)_

### Step 4: Discovery Questions

Sirf 2-3 sawaal poochho, interrogation jaisa na lage:

- "Aapki abhi koi website hai, ya aap mostly Instagram/WhatsApp pe kaam dikhate ho?"
- "Jab koi naya client aapka kaam dekhna chahta hai, toh aap usse kya bhejte ho, photos, PDF ya Instagram link?"
- "Kabhi aisa hua hai ki kisi ne Google pe _'interior designer near me'_ search kiya ho aur aapko call kiya ho?"
- "Aap kis type ke projects zyada lena chahte ho, residential, commercial ya luxury?"

### Step 5: Unke Jawab ko Apne Kaam se Jodo

**Agar website nahi hai:**

> "Samajh gayi. Aapka kaam itna accha hai, aur aajkal clients milne se pehle hi online check karte hain. Ek proper portfolio website ho toh pehli impression hi premium lagti hai, aur Google se bhi inquiries aane lagti hain."

**Agar website hai par purani ya basic hai:**

> "Achha, website toh hai. Kya usse aapko inquiries aati hain, ya woh bas aise hi padi hai? Kyunki hum mostly yahi dekhte hain ki website hoti hai par clients laane ka kaam nahi karti."

**Agar sab Instagram se chal raha hai:**

> "Instagram badhiya hai! Bas ek cheez hai: Instagram pe log scroll karke aage badh jaate hain, jabki website pe woh aapke projects, process aur reviews ek jagah dekhte hain. Isse trust jaldi banta hai, especially high-budget clients ke saath."

### Step 6: Soft Close

> "Kya main aapko WhatsApp pe hamare kuch interior designer clients ki websites ke samples bhej sakti hoon? Aap free time mein dekh lena, aur pasand aaye toh ek **15 minute ki call** fix kar lenge."

**Ya:**

> "Kya is hafte aapke paas 15 minute honge? Main aapko dikha deti hoon ki aapke liye website kaisi dikh sakti hai, bilkul free, koi commitment nahi."

### Step 7: Closing

> "Thank you so much **[Naam]** ji, aapne time diya. Main abhi WhatsApp pe details bhej rahi hoon. Have a great day!"

## Script 2: Jab woh poochhein "Aap kya kya services dete ho?"

Pehle ek sawaal se shuru karo, phir services batao:

> "Sure! Bas pehle ek cheez jaan loon taaki main aapko sirf kaam ki baat bataun. Aapko zyada help kis mein chahiye, naye clients laane mein ya apna kaam professionally showcase karne mein?"

_(Unka jawab suno, phir:)_

> "Hum interior designers ke liye mainly yeh karte hain:"

1. **Portfolio website:** "Aapke projects ki before/after photos, room-wise gallery aur aapki design style, sab kuch ek premium website pe."
2. **Inquiry system:** "Website pe WhatsApp button aur contact form, taaki client seedha aapse connect ho sake."
3. **Google pe dikhna (SEO + Google Business Profile):** "Jab koi aapke area mein _'interior designer'_ search kare, toh aapka naam upar aaye."
4. **Mobile-friendly design:** "Zyada clients phone pe hi dekhte hain, toh website phone pe bhi perfect dikhegi."
5. **Maintenance aur updates:** "Naya project complete hua? Hum usse website pe add kar denge, aapko tension nahi leni."

_(Apni actual services ke hisaab se yeh list edit kar lena.)_

> "Aapke liye inmein se sabse zyada kya useful lagega?"

Services ki list ke baad hamesha ek sawaal poochho. Isse baat chalti rehti hai.

## Common Objections (politely handle karo)

| Woh bolein                 | Aap bolo                                                                                                                                                     |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **"Interest nahi hai"**    | "Bilkul samajh sakti hoon. Kya main bas apna number WhatsApp kar doon? Kabhi future mein zarurat ho toh yaad rahe."                                          |
| **"Abhi budget nahi hai"** | "Koi baat nahi. Hum alag-alag budget ke packages banate hain. Kya main ek basic idea bhej doon, aap aaram se dekh lena?"                                     |
| **"Website already hai"**  | "Great! Kya usse aapko regular inquiries aati hain? Agar chahein toh main free mein ek quick review karke bata sakti hoon ki usme kya improve ho sakta hai." |
| **"Instagram kaafi hai"**  | "Instagram bahut accha hai! Website uske saath mil ke kaam karti hai, Instagram pe attention milta hai aur website pe trust."                                |
| **"Details bhej do"**      | "Zaroor! WhatsApp pe bhej doon ya email pe? Aur kya main 2-3 din baad ek follow-up call kar sakti hoon?"                                                     |

---

## Tips

- **Smile karke bolo**, phone pe bhi voice mein feel aata hai.
- **Unhe zyada bolne do.** Lagbhag 70% woh bolein aur 30% aap.
- **Unka naam** 2-3 baar use karo, isse baat personal lagti hai.
- **Kabhi force mat karo.** "No" ko bhi respect se accept karo, kyunki aaj ka "no" kal ka client ban sakta hai.
- Call ke baad **WhatsApp follow-up** zaroor bhejo, usi din.
